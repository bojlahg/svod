# Интерфейс «Свода»

Принятая переработка интерфейса, 24 ноября 2026 года.

Рабочая область базы использует одну боковую панель: выбор базы, поиск, дерево папок и заметок, переходы к предложениям, управлению базой и настройкам. Чтение и редактор открываются в основной области. На телефоне навигация сворачивается в меню.

## Режимы

- `/brains/:id?note=:noteId` — чтение. Перемещение и удаление находятся в меню заметки; скачивание Markdown и постоянная ссылка доступны читателям.
- `?note=:noteId&edit=1` и `?new=1` — редактор с закреплённым сохранением, Ctrl/Cmd+S, статусом черновика, панелью Markdown и общим с чтением предпросмотром. Предпросмотр и боковую панель можно скрыть.
- `?view=review` — отдельная очередь предложений и сравнение текущей и предлагаемой версий. Прямая ссылка на ожидающее предложение переводит проверяющего в этот режим.
- `?view=manage` — индекс, импорт, загрузка, экспорт и сведения о базе. Читатель видит диагностику и экспорт; изменения индекса и импорт доступны редакторам, предложения — проверяющим, управление участниками — владельцу.

Общие страницы используют Inter из локального файла, нейтральные тёмные поверхности и обычный шрифт для подсказок и действий. Моноширинный текст оставлен для Markdown, кода и технических идентификаторов. Для новых элементов добавлены русские переводы.

## Сохранение и совместимость

Состояние «сохранено» соответствует отправленному снимку текста. Ввод во время запроса остаётся несохранённым. Первое сохранение новой заметки закрепляет возвращённый ID; следующие сохранения обновляют эту заметку. Пока есть более новый текст, редактор не обновляет маршрут с перемонтированием компонента.

Текст отправляется существующим JSON-транспортом. Сохранение без изменений сохраняет исходные BOM, CRLF, идентификаторы фрагментов и векторы. Панель вставки Markdown использует смещения из нормализованного DOM-значения textarea. Реальные переходы между заметками используют отдельные экземпляры редактора.

Черновики защищены при переходах по ссылкам, выборе базы, закрытии вкладки и обычном переходе назад. Режим фокуса сбрасывается при закрытии редактора. При принятии предложения защита сохраняется до завершения запроса; одновременное сохранение и принятие заблокировано.

Используются существующие проверки доступа, версии предложений, импорт и индексация. Серверная политика ролей и токенов не менялась. Существующий обход проблемы обновления дерева в production через успешный JSON-запрос и перезагрузку сохранён.

## Проверки

- `npm test`: 286 тестов пройдено; `typecheck`, `lint`, `check:i18n` и production-сборка прошли.
- Headless Chrome против production-сборки и отдельного PostgreSQL: буквальное сохранение Markdown; Ctrl+S; вставка Markdown; ввод во время сохранения существующей и новой заметки; отсутствие дубликатов; ошибки сети и некорректный ответ сервера; отмена и подтверждение выхода из черновика; переход назад; смена заметки; выход из фокуса.
- Проверены русский интерфейс, локальная загрузка Inter, ширины 1440 и 393 px, мобильное меню, доступ читателя к скачиванию и экспорту без управляющих кнопок и отказ поддельному запросу записи.
- Проверены прямой URL предложения, повторные сохранения с актуальной редакцией, защита во время принятия и переход к принятой заметке по её ID.
- Через интерфейс проверены создание и переименование папки, перенос заметки без смены ID, поиск с выделением в дереве и импорт Markdown с предпросмотром и сохранением BOM/CRLF.
- Просмотрены страницы баз, создания базы, профиля, токенов, участников и мобильного входа. Проверки выполнялись на синтетических данных; развёртывание на dualist не выполнялось.

Реализацию выполняла обычная Muse Spark 1.3 через OpenCode (`opencode/muse-spark-1.3`, `--variant xhigh`) после согласия пользователя на замену Contributor. Архитектор проверил изменения и вернул найденные ошибки на доработку. Четыре сеанса OpenCode сообщили суммарную стоимость около $3.78 с баланса.
