Установка частной базы (3 файла: compose.yaml, .env.example, install.txt)

1. Скопируйте .env.example в .env и впишите почту и пароль администратора
   (MOZG_ADMIN_EMAIL и MOZG_ADMIN_PASSWORD).

2. В каталоге с этими файлами выполните:
   docker compose up -d

3. Откройте http://localhost:3300 и войдите этим администратором.

4. Пока модель загружается, заметки уже открываются и правятся, поиск
   по словам работает, поиск по смыслу включится после готовности модели.

5. Смена пароля в .env и перезапуск контейнера app меняет пароль
   администратора.

6. Обновление — новый тег SVOD_IMAGE / SVOD_EMBED_IMAGE и снова
   docker compose up -d, тома не удалять.
